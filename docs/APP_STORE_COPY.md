## App Store Review Notes

**Special Instructions for Apple Reviewers:**

Thank you for reviewing LuminaVerse! Here's what to expect:

**Login:** No login required - open and use immediately

**Key Features to Test:**

1. View daily verse on Home screen
2. Save verse to Favorites (tap heart icon)
3. Tap "Bible" tab → search for "love" to test verse search
4. Settings → Download a Bible version (KJV recommended, ~2 min download)
5. Settings → Change theme color to see visual customization
6. Settings → Toggle meditation music on/off

**Notifications:**

- App requests notification permission for daily verse reminders
- Users can enable/disable in Settings
- Default time: 8:00 AM (customizable)

**Donations:**

- Optional donation link in Settings
- Processed through Square (external)
- Not an in-app purchase (IAP)
- Clearly labeled as optional support

**Network Usage:**

- Fetches daily verses from bible-api.com
- Bible downloads use same API
- All content works offline after download
- No user data collected or transmitted

**Test Account:** Not needed - no login required

**Demo Video:** Available in App Preview

If you have any questions, please contact: scottpowers@example.com
