# Screenshot Text Overlay Design Guide

**Purpose:** Optimize App Store screenshots with compelling text overlays  
**Goal:** Increase conversion rate by highlighting key features and value propositions

---

## Screenshot Strategy

### App Store Display Order:

1. **iPhone 6.9" / 6.7"** (iPhone 15 Pro Max, 14 Pro Max) - Primary, most visible
2. **iPhone 6.5"** (iPhone XS Max, 11 Pro Max) - Falls back for older devices
3. **iPhone 5.5"** (iPhone 8 Plus) - Legacy support

**Recommendation:** Create screenshots for 6.9" and 6.5" minimum. App Store uses first 2-3 screenshots as "preview cards."

## Design System

### Color Palette (Overlays):

- **Primary Background:** #000000 at 55-65% opacity (gradient)
- **Accent Colors:** Match app theme (Purple #8B5CF6, Ocean Blue #3B82F6, etc.)
- **Text Color:** #FFFFFF (white) for maximum contrast
- **Badge Backgrounds:** Semi-transparent white (#FFFFFF 30%) or theme colors

### Typography:

- **Headline Font:** SF Pro Display Bold / Inter Bold
- **Sizes:** 38pt - 52pt (headlines), 28pt - 36pt (subheadings), 24pt - 30pt (badges)
- **Line Height:** 1.2x for headlines, 1.3x for body
- **Alignment:** Center for headlines, left for lists

### Layout Guidelines:

- **Top Overlay:** 8-12% from screen top
- **Bottom Overlay:** 5-10% from screen bottom
- **Side Margins:** 5% from screen edges
- **Gradient Overlays:** Use for text readability over complex backgrounds
- **Badge Padding:** 12px vertical, 20px horizontal

## Technical Specifications

### Required Screenshot Sizes:

- **iPhone 6.9"**: 1320 x 2868 pixels (iPhone 15 Pro Max)
- **iPhone 6.7"**: 1290 x 2796 pixels (iPhone 14 Pro Max)
- **iPhone 6.5"**: 1242 x 2688 pixels (iPhone XS Max)

### File Requirements:

- Format: PNG or JPEG
- Color Space: RGB (sRGB recommended)
- Max File Size: 500KB per screenshot
- Quantity: 3-10 screenshots (4-6 optimal)

## Tools for Creating Overlays

### Free Options:

1. **Figma** (recommended) - Professional design tool
2. **Canva** - Easy templates, drag-and-drop
3. **Screenshot.rocks** - Quick mockups with device frames

### Paid Options:

1. **Adobe Photoshop** - Maximum control
2. **Sketch** - Mac-native design tool
3. **Previewed** - Specialized for App Store screenshots

### Quick Method (No Design Skills):

1. Take screenshots on actual device
2. Use Canva's "App Store Screenshot" template (1290x2796)
3. Import screenshots as backgrounds
4. Add text overlays using templates
5. Export as PNG

---

## A/B Testing Recommendations

### Test These Variations:

1. **With vs. Without Device Frames** - Frames can help or hurt depending on aesthetics
2. **Text Overlay Intensity** - Light overlays vs. bold overlays
3. **Messaging Focus** - "FREE" vs. "NO ADS" vs. "OFFLINE"
4. **Screenshot Order** - Daily verse first vs. Bible search first

### Metrics to Track:

- App Store impressions → product page views
- Product page views → downloads
- Screenshot carousel engagement (Apple provides limited data)
